拆特音频槽位（仅支持 PCM WAV）

请把你有权使用的原始音频片段放到本目录。项目不会生成、下载、变声或重新分发这些片段；缺失时只显示一次提示，自动战斗仍会继续。

no_slime_ang.wav          无有效战斗时：EZ“我没有史莱姆 ang 啊”
try_minnie.wav            接管成功时：EZ“来吧，试一下米妮”
man.wav                   接管中受伤时：科比“MAN”
dead.wav                  死亡时：EZ“亡了亡了”
mamba_out.wav             零死亡完成时：科比“MANBA OUT”
failed_boss_design.wav    死过但最终完成时：EZ“设计失败的波斯”
low_level_chaite.wav      死亡后无法继续时：EZ“低级的拆特”
boss_too_hard_for_me.wav  遇到不在当前白名单的 Boss 时：“这个波斯可是超囊的对我来说”

建议只裁掉片段前后的静音，不叠加背景音乐，也不要做过度剪辑。
升级安装会更新本说明文件，但不会覆盖 config.json，也不会覆盖或删除本目录中的 WAV。
