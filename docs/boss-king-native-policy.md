# 史莱姆王：原生循环驱动的地面跑道策略

本文区分**游戏事实、控制策略、验证边界**。它不是所有装备、场地和难度都能无伤的承诺，也不把策略名称中带 `master` 当作大师模式实战验证。

## 证据来源

- 官方社区 Wiki 的 [King Slime 策略指南](https://terraria.wiki.gg/wiki/Guide:King_Slime_strategies)，通过 MediaWiki `action=parse&prop=wikitext` API 实际读取。指南介绍可预测的跳跃次序、跑鞋提供的机动性、专家模式尖刺史莱姆压力，以及抬高平台/下落后重新登台的另一套打法。
- 本机原版 Terraria **1.4.5.8**，原始 `Terraria.exe` SHA256：`960A03BFF6050CF7BE16DFC1A7B19E10FC2C4F8F835A6A3B135A50DD9E6BA2F3`。
- 使用 `tools/research/Inspect-MethodIl.ps1` / Mono.Cecil 仅读程序集元数据，不启动游戏，不调用 AI，不复制反编译源码到项目。
- 核查方法：`NPC.AI_015_KingSlime`、`AI_015_KingSlime_FindTeleportSpot`、`UpdateNPC_UpdateGravity`、`AI_001_Slimes`。

## 核实的原生机制

| 观测 | 原生含义 | 对控制器的约束 |
| --- | --- | --- |
| 地面 `ai[1]` 为 0、1 | 接下来普通跳，初始纵向速度 -8、横向增加 4 | 保持地面间距，不凭 Boss 高度跟跳 |
| 地面 `ai[1]` 为 2 | 接下来矮跳，纵向 -6、横向增加 4.5 | 不把矮跳当作反穿窗口 |
| 地面 `ai[1]` 为 3 | 接下来高跳，纵向 -13、横向增加 3.5 | 为下一次可验证的反穿准备余量 |
| 飞行中 `ai[1]=0` 且 `ai[0]≈-200` | 刚执行过高跳 | 结合实际底部净空评估反穿，不把初始下落误判为高跳 |
| `ai[1]=5` | 缩小传送阶段 | 使用实际采样的 `localAI[1/2]` 落点，不猜随机落点 |
| `ai[1]=6` | 落点重新出现阶段 | 按重新出现的真实身体位置恢复间距 |

地面计时每 tick 增长 2；生命严格低于 80%、60%、40%、20%、10% 时，依次额外增长 1、1、2、3、4。普通/矮跳后计时设为 -120，高跳后设为 -200。它不是“半血统一加速”的两阶段循环。`aiAction` 的原生蓄势提示发生在计时达到 -30 后；本控制器另外把距离下一跳不超过 12 tick 作为提前准备政策。

这里的“低于”准确执行顺序是 `float(life) < float(lifeMax) * float常量`，不是先计算生命比值。x86/x87 中未落盘的中间乘积精度可能让数学上恰为 80% 的整数也进入原生加速分支；回归对五个阈值的上下整数分别断言，并用原生同序 IL 比较校核精确边界，不能凭十进制直觉把等号情况硬写为“不加速”。

单人模式缩小到第 60 tick 搬到实际目的地，重新出现约 30 tick 后恢复跳跃。客户端的超时分支不是同一时长；此模板不声明多人同步适配。静止不代表传送，缩小/重现也不是全程无敌，开火仍按真实 `dontTakeDamage` 和视线控制。

本体受伤达到生成小怪的阈值后生成 1–3 只史莱姆；专家分支约 1/4 换成 NPC 535。普通、专家、大师共用上述本体跳跃程序，大师不是额外杜撰的一套高跳 AI。真实 535 在干燥、站地、可见条件下，200 px 内能投射 NPC 专属尖刺 Projectile 605；专家 120 px 内为 5 枚扇形，冷却 30 tick，其他有效近距离分支为单枚、50 tick。控制器在 240 px 内提前清除可见的真实 535；这个 240 是政策提前量，不是把原生射程改成 240。普通蓝史莱姆不一律抢占 Boss 输出目标。

## 当前实现的闭环

1. 地面建立约 340 px 的中心横向间距；有逼近压力才后撤，已建立距离时松开方向键刹车并输出，保留有限跑道。
2. 按原生普通/矮/高跳次序读取状态。普通跳、矮跳都不自动起跳；不能把 Boss 中心比玩家高解释成玩家应该持续追高。
3. 高跳上升、底部已有至少 48 px 的当前头顶净空，且跑道余量较少或 Boss 已较近时，考虑反向跑到身体另一侧。
4. 反穿前复用 `HorizontalMotion` 的地面加速/反向刹车模型，最多推进 **72 个标量 tick**；每个预测位置要求整个玩家脚印都位于同一个实际观测的连续支撑区间。横向与身体交叠时保留 32 px 纵向净空，并要求在有界时间内确实清到另一侧。
5. 一次高跳至多承诺一次反穿，不因刚到另一侧又立即左右反穿。窗口消失且尚未入身位时取消；已经在身体下方则维持同一出口方向，紧急碰撞层仍可覆盖策略。
6. 传送打断反穿。已知目的地就离开目的地一侧；目的地未观测则保留当前方向，绝不把默认 `(0,0)` 当作有效目的地。重新出现后按真实身位再建立间距。
7. 专家/大师附近可射的尖刺史莱姆可以短暂成为输出目标，但史莱姆王继续充当 `PatternTarget`，其跳跃和传送状态不会因为切靶丢失。

`UseExplicitMovement` 把 0 明确定义为“松开方向 / 不跳不下落”，防止通用环绕、垂直追踪或转向滞后覆盖专用状态机。它不关闭碰撞安全层。地面模板不主动触发钩爪、冲刺或重力翻转；这些能力尚未被此模板的独立状态转换验证，不能仅因为玩家装备了就随机使用。

## 门槛、复杂度与限制

- 初始门槛为横向净空 1000 px、纵向净空 280 px、持续跑速 5.5 px/tick 和基础远程输出 12 DPS；通用要求层另有模式安全余量。它们是保守入场政策，**不等于最小装备已被证明必胜**。现有引导平台打法采用不同几何条件，不能混用其更短长度来给地面模板背书。
- 不新增逐 tick 地形扫描。复用已有有界缓存的 `FloorSupport`；反穿只做固定最多 72 次简单数值运算，没有路径树、字典创建、世界 RNG 或远程请求。目标压力检测是现有目标列表上的单次线性遍历。
- 0.3 重力、10 下落速度上限来自普通史莱姆王的原生 NPC 更新；高空与液体可降低重力。但 Boss 横向预测仍采用当前速度，不模拟未来碰撞、斜坡或场地局部顶棚。低顶棚、未知地板、倒置重力、抓钩中都不进入计划反穿。玩家局部净空不是整段 Boss 顶部轨迹的完整几何证明。
- 常规世界的 classic/expert/master 是目标范围。FTW/天顶/Remix 特殊环境不允许本实现的计划反穿，其他策略行为也不能冒充已验证的特殊种子模板。
- 当前不实现指南中的抬高平台、绳索、陷阱/岩浆或双跳登台策略。云瓶、有限飞行恢复与其他 Boss 的专用模板另行验证。
- 实际武器配置的保守弹道距离仅用作射程上限，不把弹丸理论存活飞行距离当作理想战斗间距，也不把折射水晶子弹的二次伤害计作保证输出。
- 快照回归覆盖真实阶段判别、严格生命阈值、未知目的地、0 意图、反穿一次性/取消/复位、地板与重力否决、535 切靶和开火保护。**原生胜负、死亡、受击和延迟结果必须以本次冻结代码运行的隔离引擎报告为准**；本文不把回归用例通过等同于已无伤通关。
