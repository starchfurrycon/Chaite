# 拆特固定公式路线

## 实现状态（2026-09-13）

下表是目标路线目录，不是已通过实战的支持清单。目前尚无新公式路线完成
独立多种子通关验收。旧阶段夹具在 Boss 已出现后按 F8，会按新规则拒绝接管，
不能用来验证战前召唤和通关。

当前脚本仍是原型：`CombatPlanner` 先运行旧评分器，再覆盖部分输入；坐骑专用
控制、完整冲刺来源读取、天气读取、武器准入放宽及战前召唤测试都未完整接通。
固定配装并不自动证明脚本无伤。后续验收必须检查生产调用链，而非仅测试枚举。

原生时钟映射已加入回归：猪鲨使用 ai[2]/ai[3] 作为计时/序号，光女使用
ai[1]/ai[2]。不匹配 Boss 的路线、缺失或非整数观测必须拒绝。

生产接管只在 Boss 尚未出现、玩家准备召唤时进行一次路线选择。选择结果写入
`ControlPlan.FormulaRoute`，战斗中不重新选择、不拼接能力，也不接受中途 F8 接管。

| Boss | 路线 | 战前身份 |
|---|---|---|
| 猪鲨 | 仙灵/强翼 + 冲刺 | 翅膀、冲刺来源、无遮挡的原生飞行状态 |
| 猪鲨 | 史莱姆女士鞍 | MountID 50 |
| 猪鲨 | 可靠疾旋鼬/桃旋鼬 | MountID 64/65 |
| 光女 | 强翼 + 冲刺 | 强翼、冲刺来源、无遮挡的原生飞行状态 |
| 光女 | 扫帚 | MountID 23 |
| 光女 | 雨天虾松露 | MountID 12 且原生下雨 |

武器、弹药和非机动饰品不参与路线身份判断。路线身份通过后，脚本按原生 Boss
攻击状态执行固定输入；路线未通过时播放 `never_tried_this_loadout.wav`。

每条路线必须分别按难度和多个世界种子验证。没有 Terraria 原版二进制时，静态
构建和单元测试不能替代真实隔离战斗结果。

## 战前召唤验收计划

有效案例必须在 Boss 数组为空时按 F8，完成一次真实召唤流程后才进入脚本：

- 猪鲨：海洋区域、松露虫位于钓鱼流程首位、快捷栏有可用钓竿；验证
  `BossSummonKind.TruffleWormFishing`，并确认没有中途 F8 接管。
- 光女：神圣环境、七彩草蛉位于快捷栏、昼夜条件满足；验证
  `BossSummonKind.PrismaticLacewing`，白天和夜间分开记录。

旧的 `p1-*` / `p2-*` 阶段夹具是在 Boss 已存在时注入原生字段，只能验证状态
解析和拒绝路径，不能计入公式路线胜率。每条路线的结果必须单独记录 seed、难度、
路线 ID、死亡数、完成 tick 和失败原因。
