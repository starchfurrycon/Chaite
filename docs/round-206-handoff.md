## 1. 机制定位（本轮真正的价值）

`FishronWingScript.cs` 的 5 处"沿轴线脱离"分支都写作 `horizontal = AwayFromBossAxis(gap)`，
而它是个**纯符号函数**：

```csharp
private static int AwayFromBossAxis(float gap) => gap >= 0f ? -1 : 1;
```

`gap = boss.Center.X - player.Center.X`。**玩家逃离时一旦横向越过 BOSS 竖轴，符号立刻翻转，
下一 tick 就把他送回原处** —— 这就是 §209 高频抖动的来源。

**而这些分支的注释亲口说明了意图，与实现矛盾：**
- 鲨鱼龙卷分支：*"Clear it **horizontally for the whole phase**; the column cannot follow."*
- 引龙卷分支：*"**Fleeing the Boss reaches that edge on its own and never crosses him.**"*

**注释假设"逃离 BOSS 就永远不会越过他"—— 实测该假设不成立**（§209：同向段中位数仅 1–72 tick，
净位移仅占总位移 0.6%–16%）。**"整阶段持续脱离"的意图被"逐帧跟随轴线符号"完全破坏。**

**这是逻辑错误而非参数选择，且与 DPS 无关** —— 正是 §206.5 所述"参数杠杆必然零和"之外的那类候选。

任何"让走位更果断"的修改都会同时剥夺这个手段。**

## 方法要点

* **改动行为前先做默认路径逐字节回归。** 本轮先验证 4 点一致，才解释 A/B 结果。
* **阈值指标（如 `|vx| < 0.5`）会被合法的过零污染** —— 判断"控制失效"前先测**状态转移**。
* **计算战斗统计前排除 BOSS 死亡后的行**；**只算带 `plan` 的行**（接管前无 `plan`，会污染比例）。
* **`npcs[i].ai` 是数组** —— 解析 `ai[0]` 状态、`ai[2]` 计时、`ai[3]` 序列。
* **BOSS 每帧读自身 `life` 决定攻击组**（§200）。**验收台是确定性的**，每个配置跑一次即可。
* **`-maxticks` ∈ [600, 24000]；`-WallSeconds` 上限 900。**
* **`dps ≤ 780` 在 6000 tick 内数学上不可能击杀**（78000/100 秒）。
* **不要 `git add -A tmp`** —— `tmp/video/*.mp4` 最大 175 MB，超 GitHub 限制，已 ignore。
* **长扫描前先校验 `Terraria.exe` 哈希**（§187.0）。
