# 拆特玩梗登记表（项目记忆）

这份文件是**梗的单一事实来源**：以后再加梗文本、梗图、音频槽位，先来这里登记，
避免同一个人名/台词在不同文件里写成不同版本。

项目对梗素材的硬规则（与音频一致，不因为方便而放宽）：

- **不生成、不下载、不变声、不分发**任何第三方梗素材。
- 文本台词可以内置（短句，属于引用/戏仿）。
- 图片与音频只提供**槽位**：`Terraria/Chaite/Audio`、`Terraria/Chaite/Memes`，
  由使用者放自己有权使用的东西。
- 控制台自带的猪鲨与饰品图形是**本体贴图**，运行时从使用者自己的
  `Content/Images/*.xnb` 读出（见第三节），既不是自绘也不是任何人的照片；仓库与
  安装包不含这些美术资源。

## 二、科比梗

| 梗 | 用法 |
|---|---|
| **MAN** | 接管中受伤时的短促喊声；音频槽位 `man.wav`（`AudioCue.Man`），冷却 45 tick |
| **MANBA OUT** | 零死亡完成；音频槽位 `mamba_out.wav`（`AudioCue.MambaOut`） |

F8 武装成功复用同一个 `man.wav`（`AudioCue.MonitorArmed`）——
`try_minnie.wav` 保留给真正的接管瞬间，两者不混用。

前端里科比梗由梗语承担（`MemeVoice` 的「MAN」「MANBA OUT」），
不再画篮球：控制台现在只画本体贴图，而篮球没有对应的本体素材。

## 三、游戏元素贴图

这些是 Terraria 本体的元素，控制台**直接使用本体贴图**，不再自绘：

| 元素 | 素材 | 出现在哪 |
|---|---|---|
| 猪鲨公爵 | `NPC_Head_Boss_4` | 标题旁主徽章、猪鲨栏标题 |
| 松露虫 | `Item_2673` | 猪鲨栏「用松露虫召唤」 |
| Lilith的项链 / 气球束 / 羽落药水 | `Item_5130` / `1164` / `295` | 猪鲨配装卡 |
| 仙灵之翼 / 猪龙鱼之翼 | `Item_761` / `2609` | 猪鲨配装卡 |
| 蛙腿 / 克苏鲁护盾 | `Item_2423` / `3097` | 冲刺配装卡 |
| 可靠的疾旋鼬 / 疾旋火鼬 | `Item_6150` / `6151` | 疾旋鼬配装卡 |

**贴图怎么来的**：管理器运行时用 XNA 的 `ContentManager` 读玩家自己的
`Content/Images/*.xnb`，缓存到 `Terraria/Chaite/Sprites/`。此前这里写"必须自绘，
因为原版贴图是 LZX 压缩读不出来"——**这个结论是错的**。Terraria 的 XNB 头部
`flags=0x80` 确实是 LZX 压缩位（`0x01` 才是 HiDef），但 XNA 自带解压，不需要自己
实现 LZX 解码器。代价是提取需要活动 `GraphicsDevice`，管理器因此固定 x86；
没有显示设备的机器显示中性占位框。仓库与安装包仍不含任何 Re-Logic 美术。

Boss 头像索引读自 Terraria.exe 内嵌的 `NPCID.Sets.BossHeadTextures`
（`(npcType, headIndex)` 成对表），物品与 Boss 的中文名读自内嵌的 `zh-Hans`
本地化资源，都不自行编造。

## 四、梗图槽位

目录：`Terraria/Chaite/Memes/`（安装时创建，附 `README.txt`）。

- 只读顶层，支持 `.png .jpg .jpeg .bmp .gif`。
- 按文件名排序，最多显示 8 张，单张超过 512px 自动缩小，缩略图 96px。
- 解码失败**跳过**，不抛异常、不中断安装器。
- 建议命名前缀：`10-ezfic`、`20-skeletron`、`30-slime-saddle`、`40-kobe`。

## 七、前端台词池（`MemeVoice` 逐时段，逐字）

控制台头部那行小号灰字按界面状态轮换。**每一行都必须逐字取自本登记表**，
不得为了通顺而改写、压缩或新编——所有者 2026-09-23 指令原文：
"你对'梗'进行了一些加工，尽量使用梗的原文"。

池子在时段间重复是**故意的**：本表第一节把这一组称作一个"前端头部梗语池"，
某个时段没有自己的登记台词时就从本表取。

| 时段（`MemeMoment`） | 台词（逐字） |
|---|---|
| `Boot` | 来吧，试一下米妮 / 星星炮大战骷髅王 / 桑百颗 |
| `Inspecting` | 正在看这个 BOSS 是不是设计失败的 / 打这个设计失败的 boss 必须要有 300 颗 / 桑百颗 |
| `Ready` | 来吧，试一下米妮 / 桑百颗 / 星星炮大战骷髅王 |
| `Installed` | 来吧，试一下米妮 / MAN / MANBA OUT |
| `Blocked` | 这个波斯可是超囊的对我来说 / 从来没试过哦 / 我没有史莱姆 ang 啊 |
| `Busy` | 桑百颗 / 星星炮大战骷髅王 / 来吧，试一下米妮 |
| `Footer` | MANBA OUT / MAN / 亡了亡了 |
| `Scope` | 见第五节（三条，逐字一致） |

> 新增或修改台词时**先改本表再改代码**，两边必须逐字一致。
> `UiSmokeTest.ValidateMemeElements` 会检查池子非空、索引不抛、以及
> `桑百颗` 与 `MANBA OUT` 两个锚点仍在。
