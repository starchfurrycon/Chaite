# 猪鲨／光女固定公式来源审核（2026-09-14）

本文只记录能够从公开完整实况中逐段复核、并能映射到原版 AI 时钟的输入规则。
“无伤”标题、Wiki 的一般建议和单次成功都不能单独取得生产支持资格。视频副本和接触表
仅保存在忽略的 `artifacts/external-formula-research-20260914/`，不提交转载内容。

## 审核方法

1. 至少一份来源必须包含完整战斗、配装或坐骑身份、场地和动作说明。
2. 另找一份独立完整实况交叉核对核心动作；版本差异必须单独注明。
3. 把动作映射到 Terraria 1.4.5.8 的 `AI_069_DukeFishron` 或
   `AI_120_HallowBoss` 状态和固定攻击表，不用画面中的血量百分比猜当前招式。
4. 只有动作闭环、原生输入语义、隔离多种子结果全部通过后，路线才能在 UI 中标为支持。

## 可靠疾旋鼬／桃旋鼬 × 猪鲨

主要来源：[1.4.5 阿斯加德之避鼬无伤猪鲨教学](https://www.bilibili.com/video/BV1uJcFzeEsE)，
3:22，作者注明打法来源并给出逐阶段字幕。独立交叉来源：
[1.4.5.8 可靠的疾旋鼬无伤海外狂暴猪鲨](https://www.bilibili.com/video/BV1q7YM6zE6N)，
3:36，完整显示 1.4.5.8、同类单层跑道、持续正面对冲和零受击结果。

可脚本化合同：

- 场地是一条足够长的实体平跑道；上方另有实体挡板，负责拦截 Sharkron。不能把任意
  海滩或平台误认为这条路线。
- P1 第一冲距离过远，不发冲刺；从第二冲起，在每个 state 1 冲刺窗口用 mount 64/65
  的 type-6 冲刺正面对冲。依靠该坐骑原生接触免疫，不套用克盾反弹语义。
- 第一组五连冲后继续沿原方向清爆炸泡泡。进入 P2 前必须把角色送到世界边缘一侧，给
  P2 圆环泡泡留下整条反向跑道。
- P2 每当猪鲨越过角色后，才为下一冲换向；最后一次对冲结束后不立即换向，继续清掉
  剩余泡泡。第三冲可按来源中的跑道间距继续跑，让猪鲨追不上并把 Cthulhunado 留在后方。
- P3 使用原生固定节奏：传送后 1 冲、传送后 2 冲、传送后 3 冲。记住 state 12 的消失侧，
  在 state 11 的每次冲刺窗口朝来向对冲；不能按画面透明度自由猜测。

仍缺：跑道最小长度／挡板尺寸的原生碰撞证明、mount 64/65 的专用输入后置复核、
不同难度和多种子隔离验收。因此这仍是“已审核来源、未取得产品支持”的路线。

## 史莱姆女皇鞍 × 猪鲨

主要来源：[不用冲刺、不吃饰品的史莱姆女皇鞍打法](https://www.bilibili.com/video/BV1V23z6eE1z)，
4:12，完整讲解 W 形循环；交叉来源：
[三王前史莱姆皇后坐骑无伤大师 FTW 猪鲨](https://www.bilibili.com/video/BV1RZ4y1Z7GW)，
1:25，完整无伤实况。

可脚本化合同：P1/P2 以飞升后切入 mount 50 的高速下落组成 W 形，横向换边只发生在
猪鲨完成一次冲刺以后；P2 龙卷窗口下降时保持横移。P3 按 1/2/3 冲固定节拍交替“跳起、
踩下”。这不是普通翼类路线，也不能把 mount 50 仅当成一次临时快速下落按钮。

仍缺：完整 mount 50 起飞、落地、自动跳与换向状态读取，以及 PC 1.4.5.8 多种子复核。

## 扫帚／持续飞行坐骑 × 光之女皇

主要来源：[简单白天光女无伤走位教学（女巫扫帚）](https://www.bilibili.com/video/BV1HneWejEPP)，
10:46，逐招解释方向和换向原因；独立交叉来源：
[纯坐骑无伤白天光女教学](https://www.bilibili.com/video/BV1hu4y1s7Y7)，第一部分 3:45，
用方向图展示完整 P1/P2 循环，并明确扫帚可沿用、传奇加速应使用扫帚。

两份来源共同证明的脚本形态：

- 输入不是“永远绕圈”，而是由固定攻击表驱动的闭合象限序列。
- 冲刺结束立即反向拉开，避免光女瞬移后贴身；太阳舞在光束完全展开前进入靠近圆心的
  慢速区域；七彩矢持续向一个新象限离开；空灵长枪沿其固定扇形边缘绕过。
- P2 的长枪、七彩矢、冲刺、彩虹和太阳舞继续固定的右下／右上／左下／左上组合；一个
  完整循环会产生净高度漂移，因此只在固定重定位窗口做高度校正，不能逐帧追 Boss。

这套动作可映射到 AI_120 的状态 `2/4/5/6/7/8/9/11/12` 及 P1/P2 固定表索引。
仍缺逐帧方向表的代码化复核、type-23 活动身份和 mount 输入门禁、昼夜／难度多种子验收。
