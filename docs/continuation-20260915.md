## 一、用户口述的权威设定

1. **泡泡该被打掉，不该靠走位躲。** 泡泡是能被高攻速或大范围武器打破的，
   所以"左右闪躲"本身就是遗留状态机的缺陷。此前的清泡武器切换**方向是对的**
   （想让武器承担清泡），但实现把它做成了整段不开火，见
   `docs/fishron-threat-identities.md`。
2. **审核路线清单**（只有这些配装允许用于对应 Boss；小模型若启用也只能用这些）：
   - 猪鲨：① 蛙靴 + 仙灵翅膀及同级翅膀 + 可靠冲刺来源（克苏鲁之盾／忍者大师套装／
     水晶刺客套装）；② 史莱姆女士鞍；③ 可靠的疾旋鼬／桃旋鼬；
     ④ 蛙靴 + 猪鲨翅膀及同级强力翅膀 + 可靠闪避来源。
   - 光之女皇：① 蛙靴 + 猪鲨翅膀及同级强力翅膀 + 冲刺；② 扫帚飞行坐骑；
     ③ 雨天时的虾松露坐骑。
3. **小模型是最终手段，不是首选**：只有固定状态机被证明无法取胜时才考虑，
   按"每个 Boss × 每种配装"训练，且只允许走上面的审核路线。资源开销过大。
4. **测试精简是次要目标**：当前近 750 个用例是先前 Agent 的遗留膨胀，
   欢迎清理，但不要因此耽误战斗闭环。

## 三、本轮被数据证伪的两个假设（不要再试）

1. **跑道左边界不可达，是承重的。** 原生 `Player.BordersMovement` 写死 `num = 640`，
   把 `position.X` 夹到 `leftWorld + 640` 并清零该轴速度——所以 `_bandLeft =
   worldLeft + 260` 在真游戏里也不可达（夹具物块扫描 `outside=0` 证明 x=640 是原生保底，
   不是夹具几何）。但把边界推到原生边界后：tick 670–730 的泡伤整簇消失（改前 9/9，
   改后 0/6），**六条种子全败**，全部死于跑道尽头的龙卷风。
   → 代码里在 `_bandLeft` 处留了"别再修"的注释。
2. **冲刺的逃逸侧必须每帧重算，不能锁定。** `_chargeHorizontal`（`4c307ad` 的顺手改动，
   随清泡武器一起被回滚，从未单独量过）补测后十条只有 1 胜、受击 78。
   → 判据：**被事件穿过的量该锁（贴身、悬停窗口），被持续跟踪的量不该锁（冲刺瞄准）**。
   注意 `docs/tutorial-pattern-notes-20260913.md` 里"latching the charge escape direction
   for the group"这句已被证伪，该文件已改正。

## 四、逐状态审计表（判据：一个相位区间内 `plan.horizontal` 变号率）

| 分支 | 区间 | 变号 | 变号率 |
|---|---|---|---|
| `bubble-line` | 41 | 16 | **39%** |
| `charge-horizontal` | 131 | 13 | 10% |
| `standoff` | 170 | 13 | 8% |
| `charge-descend` / `personal-space` / `charge-ascend` | — | 各 3 | 2–4% |
| `precharge-jump` | 403 | 0 | 0% |
| `tornado-bait` / `tornado-clear` / `sharknado-exit` | 119 | 0 | 0% |

`bubble-line` 的 39% 按用户口述就是缺陷本身（Boss 在吐泡期间绕圈，逐帧"远离 Boss"
让玩家原地左右摇）。本轮删掉了这个逐帧推导，并把只服务于它的
`AwayFromBoss` / `Split` / `DominantAxisFraction` 一并删除（脚本 -50/+11 行）。

但"删掉闪躲"之后**替代动作用什么**，两次测量都给出否定答案：

| 替代动作 | 胜 | 受击 |
|---|---|---|
| 守住跑道方向 `_patrol`（直线行进） | 3/10 | 83 |
| 站定开火 `horizontal = 0` | **0/10** | 83 |
| （保留原逐帧闪躲 = 当前主线） | 4/10 | 75 |

两者受击都涨到 83。所以结论必须诚实地分成两半：

- **用户的规则针对的是武器，不是走位。** "泡泡该被打掉"这一半已经生效——
  回滚清泡武器切换后泡泡阶段**不再整段不开火**，这才是那半句话要修的东西。
- **逐帧横向闪躲虽然动机是错的，但它承重。** 泡泡会跟踪玩家，直线行进等于把整条
  泡泡线拖走；站定更差，被 Boss 绕圈的轨迹把泡泡送上来。在找到**已测量**的替代动作
  之前，这段闪躲不能动。删掉它换来的不是"不再怕泡泡"，而是多挨约 8 次。

**教训**：用户否掉的是"闪躲的动机"，不等于"必须换成一个方向走"，也不等于"不动"。
在泡泡会跟踪玩家的机制下，"不动""乱走""直线走"是三件不同的事，必须分别测。
